# or_default
- Ensures a value is in the entry by inserting the default value if empty, and returns a mutable reference to the value in the entry.
  - 기본값이 비어 있을 경우 항목에 값을 삽입하여 값이 포함되도록 하고, 항목의 값에 대한 변경 가능한 참조를 반환합니다.

https://doc.rust-lang.org/stable/std/collections/hash_map/enum.Entry.html#method.or_default
