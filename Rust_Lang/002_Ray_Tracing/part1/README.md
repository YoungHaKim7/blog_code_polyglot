- The primary focus of the video is on Rust programming and issues associated with porting C++ code to Rust. As such,  I'm not so focused on the mathematics of ray tracing which is already covered in great detail in the project writeup.

- The following core Rust topics are covered:
  - Starting a new project
  - Working with multiple files
  - Structure definitions
  - Traits
  - Operator overloading (via traits)
  - A tricky bit of lifetimes when mixed with dynamic traits.
  - Object oriented programming (via traits)
